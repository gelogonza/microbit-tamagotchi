# Platform notes

Toolchain-specific gotchas. One file per platform you actually use.

These are the things that are true of your tools rather than of your project —
the failure modes that cost an hour the first time and five minutes every time
after, once you have written them down.

Add a file when you hit something that will bite you again. Keep them short and
concrete: what happened, what caused it, how to check.

```
knowledge/platform-notes/
  microbit-makecode.md      supplied — MakeCode Python and block conversion
  [your-platform].md        add as needed
```

Distinct from the Learning Manual: the manual is about *your project and your
understanding*, and it is graded. Platform notes are reference material about
*your tools*, and they are just useful.
