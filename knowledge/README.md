# Knowledge

This is the project’s working source library: assigned readings, useful
references, terms, and ideas that affect a decision.

Use `readings/` for a brief response to an assigned reading. A useful response
names the source, identifies one idea worth carrying forward, and says how it
changes—or does not change—the next project decision. Keep the response in your
own words; link the source rather than copying it here.

Use `platform-notes/` only for verified tool-specific details that you may need
again. It is a reference, not a place to paste unexamined AI output.
