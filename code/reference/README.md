# Reference

Read-only examples. Not part of your project, not submitted, not graded.

## `block_tour.py`

A catalogue of MakeCode Python syntax — one section per standard block category
(Basic, Input, Music, LED, Radio, Loops, Logic, Variables, Math, Functions,
Arrays, Text, Game, Pins, Serial, Control). Use it to look up what something
looks like in Python.

**It is not a program.** Do not expect it to behave sensibly if you flash it:
the forever loop, the background thread, and the `game` sprite all compete for
one 5×5 display. It is a phrasebook, not a conversation.

Section 9 is V2-only and contains two deliberately unverified identifiers. See
`knowledge/platform-notes/microbit-makecode.md`.
