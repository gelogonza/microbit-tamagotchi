# Curriculum

This folder starts small on purpose. It is the record of what you learn while
making the artifact, not a checklist of folders to fill.

The Learning Manual is required and remains at `learning-manual.html`. Add a
new folder or file here only when your work needs it. Name it for the work it
holds, not for a predicted course category: `notes/`, `first-enclosure/`,
`interaction-flow/`, or `gallery-media/` are all reasonable when they become
useful.

When you record an observation, write the date, what you did, what you saw,
and what you decided next. Do not edit a committed observation; add a dated
correction instead.
